# Blode Stack Preso

Next.js slide deck for Matthew Blode's "Blode Stack" talk.

## Run

```bash
npm run dev
```

Open the printed local URL and use left/right arrow keys to move between slides.

## Checks

```bash
npm run format
npm run lint
npm run check-types
npm run build
```

Speaker notes live in `docs/blode-stack-speaker-notes.md`.
